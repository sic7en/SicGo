# 使用与实现说明

**简体中文** | [English](DETAILS.en.md)

[返回 SicGo 首页](../README.md)

独立的 macOS 临时截图标注工具。使用 AppKit 原生窗口和工具栏，支持英文和简体中文。只接收 macOS 生成的截图文件，不主动获取屏幕内容，不需要 SicGo 的录屏权限。

应用常驻顶部菜单栏，不显示 Dock 图标。菜单使用原生单色图标，分为截图与导入、主窗口与设置、退出三个区域；可打开系统截屏工具、编辑图片、显示启动窗口或退出。标注窗口仍可正常激活并接收键盘输入。

自动记住上次选择的标注工具、颜色、工具栏配置和窗口位置，重新打开或重启后继续使用。更换显示器后会把窗口限制在可见屏幕内；新图片仍按自身比例显示。偏好设置只包含界面选项，不包含截图和标注内容。

## 界面语言

点击顶部菜单栏的 SicGo 图标 → **Settings… / 设置…**，或在应用内按 **Command–,** 打开原生设置窗口，启动窗口也有入口。

可选 **English**、**简体中文**、**Follow System / 跟随系统**。默认为英文，以保留原有界面习惯。切换后立即更新应用菜单、启动窗口、编辑工具提示和按钮，设置会自动保存；不会重建编辑窗口或清空标注。跟随系统按系统偏好顺序选择支持的语言，不支持的语言回退为英文。macOS 自带的文件选择器和系统截屏工具仍由系统管理语言。

## 常用设置

- **登录时启动 SicGo**：使用 macOS 原生登录项服务，默认不注册。用户勾选后才启用；如需系统批准，会显示系统设置入口。每次打开设置时读取系统真实状态，失败时显示错误并恢复实际状态。
- **启动时显示主窗口**：默认开启。关闭后启动时只保留菜单栏图标；仍可从菜单显示主窗口，打开图片不受影响。
- **记住上次的工具和颜色**：默认开启，延续原有行为。关闭后，每张新图片使用设置中的**默认工具**和**默认颜色**。编辑时临时换工具和颜色不会覆盖这组固定默认值。

标注默认值只影响新打开的图片，当前编辑内容保持不变。语言、标注和窗口偏好自动保存；登录启动状态由系统管理。

## 使用流程

1. 保持 SicGo 运行，按 macOS 系统快捷键 **Command–Shift–4** 选择区域，或 **Command–Shift–3** 截取全屏。
2. 系统写完截图后，SicGo 自动打开编辑窗口。系统选区中按 Escape 取消。**Screenshot… / 截屏…** 按钮打开 Apple 的“截屏”工具，也可使用 **Command–Shift–5**。
3. 添加文字、箭头、方框、椭圆、画笔或马赛克；支持裁剪、整图旋转。
4. **Copy** 复制当前图片并继续编辑；**Done** 复制并关闭。
5. 直接粘贴到聊天、文档或其他软件。关闭窗口或点击垃圾桶直接丢弃本次编辑。

也可以 **Open Image** 打开本地图片，或 **From Clipboard** 编辑剪贴板图片。打开的原文件不被修改或删除。

按住 Control 使用系统截图快捷键会将图片送到剪贴板，此时使用 **From Clipboard** 或 **Command–N** 打开，不会自动监听剪贴板。

## 标注操作

- 文字直接在图上输入，点击文字区域外或切换焦点完成输入；Return 也可完成，Shift–Return 换行，Escape 取消。
- 已完成的文字可直接按住拖动，双击重新编辑。其他标注单击选中后拖动，选择工具可直接拖动已有标注。
- 四角调整大小；Shift 保持比例。空心框内部可以继续添加内容。
- 箭头拖动两端调整方向与长度；Shift 按 45° 对齐。
- 指针放在选中对象上，触控板双指旋转。四角只用于缩放。
- 线宽固定为细线，缩放图形不改变线宽。
- Command–Z 撤销，Command–Shift–Z 重做；Delete 删除选中标注。
- Command–Return 完成并复制；Command–W 关闭并丢弃。

## 临时数据

运行期间，SicGo 将系统截图的目标临时设为自己的缓存目录，并关闭系统浮动缩略图，避免两套编辑窗口同时出现。截图文件写完且成功读入内存后删除；未完成或读取失败的文件保留供重试。仅处理本次运行期间新出现、带有 macOS 截图标记的图片；不处理原有文件、普通图片、符号链接或视频。

正常退出（包括 SIGTERM）时恢复之前的截图位置、目标和缩略图设置，并保留用户在运行期间主动改过的设置。macOS 27 使用截图专属设置，不改动录屏保存位置；较早系统的截图与录屏共用保存位置，录屏文件不会被 SicGo 删除。

异常终止后，设置恢复记录在下次启动时用于恢复原设置；尚未成功读取的文件可能留在缓存目录，旧文件不会自动导入或删除。缓存目录是 `~/Library/Caches/local.makstton.SicGo/System Screenshots`。

编辑对象与撤销记录只保存在内存，窗口关闭后释放。没有截图历史、自动保存、标注旁文件或顶部悬挂。复制到系统剪贴板的图片仍可粘贴，直到被其他内容替换。文件接收采用系统目录变化通知，空闲时不定时扫描。

## 资源占用

- 主窗口与设置页在需要显示时才创建，之后复用原生控件，避免反复销毁和重建的开销。截图编辑窗口仍在关闭后释放图片和标注。
- 一次绘制中，每块马赛克只生成一次低分辨率色块数据，供后续重叠马赛克复用；绘制结束后释放。预览和复制继续使用原有分辨率与绘制顺序。
- 撤销和重做合计最多 30 步，额外历史载荷预算为 128 MiB。共享原图只计一次，不重复计入当前图片；同时保守计算历史标注、画笔点和文字。裁剪、旋转以及撤销、重做后均检查预算，超出时丢弃较远的历史。当前图片始终保留，这个预算不等于整个应用的内存上限。

`bash scripts/benchmark.sh` 可重复测量 1080p、不同马赛克数量的渲染中位耗时。测试与构建产物不会打包进应用。

2026-10-24 本机同一测试图、Release 优化编译、每组 3 次的中位耗时：

| 马赛克数量 | 优化前 | 优化后 |
| --- | --- | --- |
| 6 | 4.79 ms | 3.83 ms |
| 10 | 18.83 ms | 5.25 ms |
| 12 | 59.79 ms | 5.95 ms |

这是固定场景的渲染测试，实际耗时随图片和设备变化。回归检查逐像素比较重叠、旋转以及不同预览缩放下的输出。

## 构建

需要 macOS 14+、Swift 工具链和 macOS SDK。

```sh
bash scripts/build.sh
open build/SicGo.app
```

构建脚本使用当前系统 SDK，生成 Release 应用并做本地签名。项目没有第三方包依赖。

```sh
bash scripts/check.sh
```

## 代码结构

| 文件 | 内容 |
| --- | --- |
| `App.swift` | 应用入口、启动窗口、菜单、打开与粘贴图片 |
| `Capture.swift` | 系统截图文件接收、成功读取后清理、截图设置恢复 |
| `EditorWindow.swift` | 原生工具栏、复制与完成操作 |
| `EditorPreferences.swift` | 工具、颜色与窗口位置的轻量偏好设置 |
| `SettingsWindow.swift` | 原生设置窗口、即时语言切换、登录启动与标注默认值 |
| `Localization.swift` | 界面文案与系统语言匹配 |
| `EditorCanvas.swift` | 点击、拖动、缩放、旋转和原位文字输入 |
| `EditorDocument.swift` | 内存中的图片、标注、撤销与重做 |
| `Drawing.swift` | 标注几何、命中检测和原分辨率渲染 |

这是为当前需求重新编写的独立工程，没有第三方包、截图历史数据库或主动抓屏代码。全局截图快捷键由 macOS 自己管理。
