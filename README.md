# SicGo

**简体中文** | [English](README.en.md)

**给 Codex、Claude Code 的反馈，直接标在截图上。**

SicGo 是一个轻量的 macOS 截图标注工具，为使用 Codex、Claude Code 等 AI 编程工具时的日常沟通而做。截图后直接圈出问题、画箭头、写说明，复制后就能发给 AI。

**截图 → 标注 → 复制 → 粘贴。**

功能简单，但在反复调整界面、反馈问题时很有用。

## 为什么做它

让 AI 修改页面时，经常需要解释：“这里对齐一下”“这个按钮往左移”“这一块间距太大”。只用文字描述，位置和范围不容易说清楚。

在截图上画一个框、加一根箭头、写几个字，就能把想改的地方指出来。SicGo 把这几步连在一起，让截图反馈像复制粘贴一样顺手。

例如：

- **调整界面**：框出组件，标注“与上方标题左对齐”。
- **反馈问题**：箭头指向错位或被遮挡的内容，补一句实际表现。
- **说明参考效果**：打开参考图，标出希望保留的布局、间距或细节。
- **分享前处理**：用马赛克遮住不想分享的内容，再复制图片。

## 怎么用

1. 打开 SicGo，它会常驻 macOS 顶部菜单栏。
2. 按 **⌘⇧4** 截取区域，系统截图完成后会自动进入标注窗口。
3. 用文字、箭头或方框指出要修改的位置。
4. 点击绿色勾选图标（**完成**），图片会复制到剪贴板，编辑窗口随即关闭。
5. 在支持图片粘贴的 Codex、Claude Code 等客户端中粘贴，再补充你的要求。

想继续编辑时，点 **Copy / 复制** 即可。也可以打开本地图片，或从剪贴板新建标注。

SicGo 负责准备图片，无需配置模型或 API Key，也不会自动把截图发送给 AI。图片粘贴方式取决于所用客户端。

## 保留常用的功能

| 功能 | 用途 |
| --- | --- |
| 文字、箭头、方框、椭圆、画笔 | 指出问题，写清修改要求 |
| 马赛克、裁剪、整图旋转 | 整理图片内容 |
| 移动、缩放和旋转标注 | 调整已经画好的内容 |
| 把图片粘贴到当前图片 | 将参考图作为独立对象移动、缩放和标注 |
| 撤销与重做 | 随时修正操作 |
| 复制、完成后关闭 | 标注好就能粘贴使用 |
| 中英文界面、自动记住工具和颜色 | 延续上次的选择，无需额外开关 |
| 拖动排列工具栏 | 在设置里调整图标顺序，立即同步并记住 |

文字直接在图上输入，点击其他位置即可完成；已有文字可以直接拖动，双击再次编辑。默认采用系统字体，也可以在设置中选择本机已安装的字体。

复制另一张图片后，在当前编辑窗口按 **⌘V** 即可叠加到画布中；它保持独立，可以移动、缩放、旋转或删除。旋转整图时窗口大小和位置保持不变。

选中画好的标注，按 **⌘C → ⌘V** 即可复制一份，保留颜色、大小和旋转角度。副本可以继续移动、缩放和编辑，也支持撤销。工具栏的 **Copy / 复制** 和 **Done / 完成** 始终复制整张图片。

## 轻量，用完即走

- **原生 macOS 应用**：Swift + AppKit，没有第三方包依赖。
- **常驻菜单栏**：不占 Dock 位置，可选择登录时启动。
- **使用系统截图**：读取 macOS 生成的图片，无需向 SicGo 授予录屏权限。
- **编辑在本地完成**：没有账户、云端同步或内置 AI 服务。
- **不保留截图历史**：正常读入的系统截图临时文件会被删除，标注与撤销记录只留在内存中。

关闭窗口会丢弃本次编辑；已复制的图片仍在系统剪贴板中，可以继续粘贴。打开的本地原图不会被修改或删除。

运行期间，SicGo 会临时调整系统截图的保存位置并关闭系统浮动缩略图，正常退出时恢复。如果应用异常退出或图片读取失败，可能留下临时文件。具体行为见[使用与实现说明](docs/DETAILS.md)。

## 安装

[下载安装包](https://github.com/sic7en/SicGo/releases/latest)

当前 DMG 安装包适用于 **Apple 芯片 Mac，macOS 14 或更新版本**。

打开 `SicGo-1.3.3-AppleSilicon.dmg`，将 **SicGo** 拖入 **Applications / 应用程序**，然后启动。

当前安装包使用本地签名，尚未经过 Apple 公证。

## 检查更新

在顶部菜单栏或设置页点击 **检查更新…**。有新版本时，点击 **下载更新…** 打开 GitHub 发布页，下载安装包后替换应用。

仅在点击时检查，不在后台轮询，不上传截图或标注，也不会自动退出应用。先完成当前编辑并退出 SicGo，再安装新版；个人设置会保留。

## 从源码构建

需要 macOS 14+、Swift 工具链及 macOS SDK。在项目目录中运行：

```sh
bash scripts/build.sh
open build/SicGo.app
```

运行回归检查：

```sh
bash scripts/check.sh
```

更多快捷键、设置、临时文件处理和性能说明，见[使用与实现说明](docs/DETAILS.md)。
